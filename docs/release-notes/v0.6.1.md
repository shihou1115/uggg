# ugg v0.6.1 — 話者が見つからないときに無言にしない

**リリース日**: 2026-10-30（予定。インストール版の確認と E-14 のあとタグ）
**タグ**: `v0.6.1`
**テーマ**: v0.6.0 の §6.0「見つけたが今回の裁定に含めていないもの」に計上していた「VOICEVOX の話者 ID を確かめていない」を閉じる。新機能ゼロ。

## 経緯

v0.6.0 まで、VOICEVOX の話者 ID が実在するかを保存のときにも合成の直前にも確かめていなかった。読み込んだ `.vvm` に無い話者が
設定に残っていると合成が失敗し、フロントの `console.warn` だけが残って、吹き出しは出るのに声も口パクも無く、告知も無かった
（読み上げパネルは「読み上げ完了 (N 件スキップ)」とだけ出る）。

2026-10-30 のユーザー裁定で「合成が失敗したら 1 回告知する＋設定欄で見つからない話者に印を付ける。保存は止めない」に決めた。

ai-team 体制（Claude がリーダー、Codex とローカル LLM が部下）での最初のリリース。着手前の調査と実装は Codex、レビューと検証は Claude。

## 入れたもの

| | 内容 |
|---|---|
| 1 | **合成の前に話者を確かめる** — エンジンの初期化のときに、読み込んだ話者の style ID の集合を控える。`synthesize_voicevox` は合成の前に集合を見て、無ければ合成を呼ばず「話者が見つからない」という、ほかの合成失敗と区別できる失敗にする。集合を取れなかったときは判定しない（分からないものを「見つからない」と言わない） |
| 2 | **1 回だけ告知する** — `NoticeKind::VoicevoxSpeakerMissing { slot, style_id }`。辞書キーは役で言い分ける（`voicevox_speaker_missing_main` / `_sub`。声が出ない本人が言い、相手が設定の「音声」を案内する）。（読み込み中のゴースト・役・style ID）ごとに起動中 1 回、届いたときだけ済み。VOICEVOX で鳴らす 3 つの経路（VOICEVOX モード／参照音声が無いときの代わり／高品質モードが使えないときの代わり）すべてで告知する |
| 3 | **設定欄で見つからない話者に印を付ける** — 一覧に無い保存済みの ID は「#ID (見つからない話者)」（一覧が取れないときは「#ID (未取得)」のまま）。保存は止めない |
| 4 | **話者 ID 0 と音量 0 が保存で元に戻るバグを直す** — `Number(...) ||` が 0 を落としていた（ID 0 は四国めたん・あまあまで実在する話者、音量 0 は無音）。開発方針 7 の掃討で設定パネルの同じ形 11 件を当たり、0 が有効な値の 3 件（話者 main / sub・音量）を直した |
| 5 | **記録** — spec §4.5.1・§6.0、architecture §7.3・§11.2・§11.3（v0.6.0 で載せ漏れた告知 2 行も足した）・§4.7 の `list_voices` の説明を実装に合わせた、test-plan（E-14）、取説 |
