# ugg v0.6.0 — 新しいミミとクロ・声をゴーストごとに

**リリース日**: 2026-10-24（予定。インストール版の確認のあとタグ）
**タグ**: `v0.6.0`
**テーマ**: v0.5.x で据え置いてきた「デフォルトゴースト・シェルの刷新」。ミミとクロの絵を描き直し、声をゴーストごとに
覚えるようにした。依存とモデルの版は変えていない（v0.5.7 のまま）。

## 経緯

2026-10-02 のスコープ確定では「ミミとクロは残し、2 組目を同梱で足す」だった。絵の制作中の 2026-10-24、ユーザー裁定で
**2 組目は作らず、作った絵をミミとクロの差し替えに使う**ことにした（ミミ = 魔法使いの少女、クロ = その使い魔の黒猫。
クロはもともと黒猫）。名前・一人称・口調・辞書は変えず、persona に魔女と使い魔の設定を足した。
声をゴーストごとに覚える土台（項目 2〜5）は、DnD で入れたゴーストとの間で効く。

## 入れたもの

| | 内容 |
|---|---|
| 1 | **ミミとクロの絵を差し替え** — Claude が ComfyUI（`novaOrangeXL_rexV10`）と GIMP で作り、ユーザーが候補から選んだ（ミミは C 案・マントの裾を床に広げない形に修正、クロは B 案）。4 表情 × 口パクの 16 枚。表情は通常の顔を土台に目と口だけを描き直し、前髪・輪郭・体は全フレームで同一。`shell.json` の `base_size` を絵の縦横比に合わせて main 176×384・sub 80×144 に（256×384 のままだと横に約 1.45 倍伸びる）、つつき・撫での境目を測り直した。生成モデルの使用条件はユーザーが確かめ、出力に制限が無いことを確認して同梱を決めた |
| 2 | **声をゴーストごとに覚える** — VOICEVOX の話者（設定 `tts_speakers_by_ghost`）と高品質モードの参照音声（新テーブル `ghost_voice_refs`、schema v10）。更新前の声は移行時点のゴーストに残る。旧版の `voice_refs` は作り直さずに残し、新版で作り直し・削除しても旧版が指す wav は消さない（旧版へ戻せる）。声を決めていないゴーストには 1 回だけ案内する。VOICEVOX のクレジットは実際に VOICEVOX で鳴らした声の話者で出す |
| 3 | **参照音声が無いときに無言にしない** — 高品質モードで参照音声が無い声は VOICEVOX で話し、ゴーストごとに 1 回だけ伝える（v0.5.8 までは声が出なかった） |
| 4 | **切り替えたあと、前のゴーストとの会話を AI に渡さない**（`chat_log.ghost_id`） |
| 5 | **同梱アセットの契約テストを全組へ** — `default` 決め打ちだった 9 本を、同梱のすべてのゴーストとシェルに広げた |
| 6 | **取説** — 新しいミミとクロ、声の扱い、切り替えと会話の続き |
| 7 | **右クリックメニューとトレイに「再起動」**（ユーザー要望。「終了」のすぐ上、確認のダイアログを出してから。終了と同じ後片付けをして起動し直す） |

## 実機確認（E-13）で見つけて直したもの

1. **参照音声の告知が、ミミとクロで 1 回ずつ続けて 2 回出た**（`e494cb1`）— 取り合いの鍵が「ゴースト × 声」だった。
   spec の受け入れ条件（main と sub で 2 回出ない）と項目 3 の本文が矛盾しており、実装は後者に従っていた。鍵をゴーストごとに
2. **dev で「再起動」を押すと「failed printing to stderr」で落ちた**（`ed8d4f7`）— 新しい ugg が閉じかけのパイプを引き継ぎ、
   ログの `eprintln!` が panic した。ログの stderr 側を、書けなくても落ちない形に。テスト以外のコードに panic しうる print が
   無いことを見張るテストを常設

## リリース前監査（release-audit）が出したもの — タグ前に修正（`2b62bf1`）

- **新版で参照音声を作り直す・削除すると、旧版が使う wav まで消えた** — 移行は旧版と同じ wav を指すため。spec の
  「旧版へ戻したときに旧版が使える」が成り立たなかった。旧版の `voice_refs` が指している wav は消さないようにした
- CLAUDE.md の索引が古かった（リリース作業で更新）

## 既知の制限

- 表示倍率を 0.5 まで下げると、ミミの口パクはほぼ見えない（全身の絵で顔が小さいため）
- 告知「参照音声がまだ無い」は、起動のたびに 1 回出る（起動している間に作る人がいる前提。spec どおり）
- dev の「再起動」は、開発サーバーが一緒に止まるため、起動し直した画面が表示されないことがある（インストール版では起きない）
- ローカル LLM が同じ GPU で文章を作っている間は、高品質モードの 1 文に数秒〜十数秒かかる（v0.5.8 から据え置き）
